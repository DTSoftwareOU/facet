Tools that follow you everywhere.

  • Web search for every modelModels from Anthropic, OpenAI and Google can search the web on their own. Add a Brave, Tavily, Exa, Jina or SearXNG key and every other model can search and read pages too, with sources cited.
  • MCP serversConnect remote Model Context Protocol servers, with a token or a browser sign-in. Their tools work with any model that supports tools. Anything that changes data asks first, unless you turn on YOLO mode and let it run.
  • SkillsReusable instructions the model loads when a task calls for them. Write your own or import SKILL.md files and bundles.
  • Your PC, from your phoneKeep Facet for Windows running and chats on your phone or in the browser can work in a folder on your PC: run commands, read and edit files, with approvals on the device in your hand. Requests are end-to-end encrypted, and the PC only accepts them once you allow it.
  • Pick up where your coding agent left offType /resume-from-claude or /resume-from-codex to continue a Claude Code or Codex session from the same folder, with any model you like.
  • Images, video, voices and musicPick a model for each in Settings: GPT Image, Nano Banana, FLUX, Gemini Omni, ElevenLabs and more. Ask any chat model for a picture, a clip or a song and it appears in the conversation.
  • Set up onceSearch keys, servers, sign-ins and skills sync to all your devices, end-to-end encrypted, and are ready in every new chat.

Encrypted before it leaves your phone.

Chats, files, assistants and API keys are encrypted on your device with a key only you hold. The sync server stores ciphertext it can’t read, and it never receives your password.

What the sync server can see

  • Your email address
  • How many encrypted items you’ve synced, their rounded-up sizes and when they changed
  • Names of your signed-in devices and their IP addresses

What it can’t read

  • Conversations, messages and attachments
  • Your API keys
  • Assistants, saved prompts and settings
  • Your password (only a derived key ever leaves the device)

Prompts go straight from your phone to the AI provider you choose, under that provider’s terms; Facet’s server never relays them. If you forget your password, your recovery code restores access. Without it, encrypted data can’t be recovered by anyone, including us. Read the privacy policy.

Open source, and yours to host.

Facet is licensed under Apache-2.0, and the app and sync server live in one repository. Use the hosted server at facet.dtsoftware.io, or run your own and point the app at it from Settings.

  • Steady streamingReplies arrive at an even pace and render block by block, so long answers full of code and tables don’t stutter.
  • Works without an accountEverything is stored on your phone. Create an account later and your chats sync, encrypted.

Get started in three steps.

  1. Open or install Facet

    Use it in your browser, install the Windows app, or open the APK on any phone running Android 8.0 or later. Your chats follow you between all three.

  2. Add an API key

    Paste a key from OpenAI, Anthropic, Google, OpenRouter or another provider. Facet checks it and loads the models.

  3. Create an account, if you like

    Sign up to sync encrypted chats across your devices, and keep the recovery code Facet gives you somewhere safe.
